# Завдання 11. Системний виклик чи звичайна функція (легке)

Поясніть, чим системний виклик відрізняється від звичайної функції Python, і чому один `print("привіт")` не обов'язково дає один системний виклик `write`.

**Умова.**
- Своїми словами поясніть, що таке системний виклик і навіщо програмі потрібен перехід у ядро.
- Поясніть, чому в трасі `strace` для виклику `open(...)` видно `openat`, а виклик `print` може не мати власного `write`.
- Наведіть один приклад дії, яку програма не може виконати без звернення до ядра.

**Обсяг.** 5-8 речень.

---

Відповідь:

Системний виклик — це програмний інтерфейс, за допомогою якого додаток у просторі користувача звертається до ядра операційної системи для виконання привілейованих дій. Перехід у ядро необхідний через апаратний захист, оскільки звичайні програми не мають прямого доступу до обладнання чи пам'яті інших процесів. У трасі strace виклик open(...) відображається як openat, оскільки сучасні ядра Linux реалізують відкриття файлів саме через цей виклик відносно файлового дескриптора каталогу. Один виклик print("привіт") у Python може не породжувати системний виклик write через буферизацію даних на рівні бібліотеки Python. Прикладом дії, яку програма не може виконати без ядра, є створення нового процесу через fork.
