# Завдання 11. Системний виклик чи звичайна функція (легке)

Поясніть, чим системний виклик відрізняється від звичайної функції Python, і чому один `print("привіт")` не обов'язково дає один системний виклик `write`.

**Умова.**
- Своїми словами поясніть, що таке системний виклик і навіщо програмі потрібен перехід у ядро.
- Поясніть, чому в трасі `strace` для виклику `open(...)` видно `openat`, а виклик `print` може не мати власного `write`.
- Наведіть один приклад дії, яку програма не може виконати без звернення до ядра.

**Обсяг.** 5-8 речень.

---

Відповідь:

Системний виклик — це запит програми з простору користувача до ядра на виконання привілейованої дії через спеціальну інструкцію процесора[cite: 63, 75]. Перехід у режим ядра необхідний через апаратний захист, оскільки програми у просторі користувача не мають прямого доступу до апаратного забезпечення та захищеної пам'яті ядра[cite: 62, 63]. У трасі strace виклик open(...) відображається як openat, оскільки сучасна бібліотека glibc та ядро Linux реалізують базову логіку відкриття файлів через цей системний виклик відносно дескриптора поточного каталогу[cite: 65]. Один виклик print("привіт") у Python може не породжувати системний виклик write через буферизацію даних на рівні бібліотеки Python та sys.stdout, через що фактичний запис відбувається лише при заповненні буфера або його скиданні[cite: 22, 74]. Прикладом обов'язкової дії для ядра є створення процесу через clone/fork або отримання ідентифікатора getpid[cite: 61, 65].
